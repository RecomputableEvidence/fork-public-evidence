# Non-promotion boundary

This successor clarification changes only the explicit byte-serialization contract used to recompute evidence-range hashes.

It does **not**:
- rewrite or replace Run 003;
- change any Run 003 line range or SHA-256 value;
- change any M11–M25 detector result;
- create Stage 3 adjudication;
- establish semantic correctness, framework validity, prevalence, production readiness, truth, authority, compliance, or deployment standing.

The clarification is prospective. Historical Run 003 remains frozen with its original under-specification visible through its recomputation record.
