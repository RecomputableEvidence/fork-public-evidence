# Fork Proof Atlas v0.1

The Fork Proof Atlas is a bounded public routing surface for compact,
recomputable demonstrations of already-preserved evidence behavior.

It does not create new semantic standing for the underlying evidence, replace
source artifacts, convert a review into endorsement, or admit a packaging
candidate.

## Packaging rule

Each proof must:

1. bind its exact source and closure coordinates;
2. invoke the underlying checker rather than restating its result;
3. derive its human-readable summary mechanically;
4. preserve changed and unchanged dimensions;
5. include at least one executable adverse case;
6. preserve exterior-review standing and corrections;
7. distinguish underlying evidence standing from packaging standing; and
8. state all non-effects.

The Atlas is an explanation and recomputation layer. It is not an authority,
approval, compliance, truth, correctness, or present-reliance layer.
