# Fork Reviewer Start Here v0.2

## Purpose

This is the short entry path for a reviewer encountering Fork without prior repository context.

Fork is a research implementation for preserving recomputable evidence across AI-assisted workflow boundaries without silently transferring claim scope, review standing, authority, approval, or execution permission.

## Ten-minute path

1. Read the root `README.md`.
2. Read `docs/proof-atlas/PROOF-001-review-does-not-silently-travel-v0.1/README.md`.
3. Run the bounded Proof 001 wrapper if your environment permits:

```bash
python tools/run_proof_001_review_does_not_silently_travel_v0_1.py --json
```

Then state in your own words:

- what Fork preserved;
- what the proof checked;
- what the result did **not** establish.

## Review discipline

For any statement, identify the smallest artifact that supports it.

Keep these distinctions explicit:

- repository presence ≠ admission;
- source-evidence admission ≠ proof-packaging admission;
- structural verification ≠ truth;
- recomputation ≠ generalized validation;
- exterior observation ≠ endorsement;
- preserved authority context ≠ authority transfer;
- repair ≠ erasure of predecessor failure;
- missing evidence ≠ negative evidence.
