# Fork SCTD Execution Cycle 001

This package binds the preregistered SCTD v0.1 candidate protocol to an executable TF-00 lossless-transfer harness and its first executed control chain.

Contents:

- `bindings/` — byte-preserved preregistration protocol, T0 record, and immutable T0 source.
- `harness/` — executable Python harness.
- `config/` — preregistered TF-00 chain configuration.
- `runs/` — two 10-generation raw-byte-copy replicates and per-generation receipts.
- `reports/` — machine-readable and human-readable control summaries.
- `verification/` — fresh recomputation and fail-closed mutation self-test.
- `SHA256SUMS.txt` — package-wide file manifest, generated after execution and verification.

No repository admission, TF-01 execution, semantic generalization, or governance promotion is performed by this package.
