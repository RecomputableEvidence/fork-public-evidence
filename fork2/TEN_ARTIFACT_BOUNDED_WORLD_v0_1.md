# Fork 2 ten-artifact bounded world v0.1

## Question

Can Fork preserve ten simultaneously evolving artefact lineages end-to-end without importing identity, authority, claims, findings, or standing merely because another artefact or transition is adjacent?

This is a bounded simulation. It does not freeze a universal artefact ontology, promote relation standing, or establish production readiness.

## Population

The simulation contains ten heterogeneous artefact roots:

1. `A1` — immutable source document.
2. `A2` — materially revised report with explicit successor identities.
3. `A3` — stable bytes with changing authority state.
4. `A4` — stable artefact identity with changing claim state.
5. `A5` — observation that becomes truncated.
6. `A6` — exterior return with source origin not bound.
7. `A7` — failed recomputation followed by a passing successor.
8. `A8` — branching derivative with sibling-specific standing.
9. `A9` — merge artefact preserving parent-specific differences.
10. `A10` — content-identity mismatch routed through remediation/disposal.

## Population-level invariant under pressure

```text
PROPERTY OF Ai
MAY NOT BECOME
PROPERTY OF Aj

WITHOUT AN EXPLICIT
BOUND RELATION
AND TRANSITION BASIS.
```

The simulation deliberately checks that:

```text
AVAILABLE NEARBY != BELONGS HERE
SAME BYTES != SAME AUTHORITY STATE
SUCCESSOR PASS != PREDECESSOR PASS
SIBLING SUCCESS != SIBLING STANDING
MERGE MEMBERSHIP != SHARED STANDING
EXTERIORITY != INDEPENDENCE
IDENTITY MISMATCH != MALICE
```

## Longitudinal conditions exercised

- immutable identity across time;
- material revision creating explicit successor identities;
- authority expiry and reestablishment without byte change;
- claim-state change without artefact identity change;
- observation truncation without completion from adjacent evidence;
- exterior return with bounded origin standing;
- failed recomputation preserved after later success;
- branch-specific findings;
- merge preservation of conflicting parent standing;
- identity discontinuity blocking direct advancement.

## Router-level flows exercised

The existing five-phase router is used where its current semantics apply:

```text
INBOUND
→ EXAMINE
→ DETERMINE
→ [RESOLVE → DETERMINE]*
→ OUTBOUND
```

The simulation confirms that remediation cannot be skipped for an open identity mismatch and that failed recomputation must return through redetermination before outbound eligibility.

## Preserved open seams

The simulation intentionally does not repair two already-known seams:

### BW-001 — cross-subject successor relation

A material revision such as:

```text
A2.2 SUCCESSOR_OF A2.1
```

is preserved in the simulation relation layer, while the current router correctly rejects silent `subject_id` substitution.

This demonstrates the need for a relation/event layer if Fork is to represent a material successor without weakening subject identity protection.

### BW-002 — unresolved outbound

The current router rejects direct:

```text
DETERMINE(UNRESOLVED)
→ OUTBOUND(UNRESOLVED)
```

The A6 path therefore resolves to `ARCHIVE_ONLY` before outbound in this simulation. Whether bounded unresolved evidence should be directly emittable remains open.

## Success conditions

Within this bounded fixture, the simulation seeks all of the following:

```text
TEN ROOT ARTEFACTS ENTER
TEN ROOT LINEAGES REMAIN ACCOUNTABLE
ZERO UNDECLARED CROSS-LINEAGE INHERITANCE
```

and:

1. exact content identity is retained where declared immutable;
2. byte-changing revisions remain distinct successors;
3. authority can change independently of content identity;
4. claim state can change independently of content identity;
5. missing/truncated observations are not completed from adjacency;
6. exteriority does not imply independence or actor identity;
7. predecessor failure survives successor success;
8. sibling branches preserve independent standing;
9. merges preserve parent-specific differences;
10. identity discontinuity cannot skip remediation/redetermination;
11. each lineage remains reconstructable from preserved temporal coordinates.
